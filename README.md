# ChatGPT Calculator

A responsive calculator built with plain HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Percentage, decimal, sign toggle, and delete
- Keyboard support
- Light/dark theme toggle
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## GitHub Pages
In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. Your site will be published at:

`https://YOUR-GITHUB-USERNAME.github.io/chatgpt_calculator/`
